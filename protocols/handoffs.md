# Handoffs

Use templates/handoff.md. Name the owner and recipient, objective, artifact revisions, environment, evidence, reproduction commands, acceptance conditions, unresolved risks, and required permissions. Distinguish completed work from planned work. Include a rollback path and the next useful action.

A receiving member checks scope and evidence rather than assuming the sender's conclusion. Use a short summary plus locators; keep sensitive code in its project repository. A handoff does not transfer permission to publish or contact collaborators.
