# Learning loop

At task start: validate, route, then assemble scoped context. Read the bundle and identify assumptions and missing evidence. The repository supplies reusable context only when the session actually loads it.

At task end: reflect on expected versus actual outcomes, capture candidate memories, link evidence and counterexamples, and request independent review. Verify and then adopt only within demonstrated scope. Accumulate cross-project evidence before generalizing. Use recurring behavioral evidence to propose identity amendments, run scenarios, and record trial outcomes. Git commits preserve the sequence; they do not certify truth.
