# Collaboration

One primary owner per artifact prevents conflicting writes. Before editing, agree on boundaries and handoff files. When anchoring is a risk, solicit independent initial specialist assessments before sharing a proposed explanation. Parallel roles are useful only when the work and evidence are genuinely independent.

Builders cannot certify their own important implementations. Keep an implementation handoff separate from the reviewer report. State shared code paths and assumptions. Atlas integrates conclusions but must record a rationale when rejecting specialist advice. Preserve dissent and its minimum resolving experiment.
