# Task routing

Start with the smallest team that covers the objective. The CLI uses transparent lexical routing; it recommends roles and reasons, never spawns agents. Inspect the recommendation against the actual task. Curie handles mechanics, Gauss sensitivities and numerics, Ada software and HPC, Vera independent verification, Iris communication, Scout primary sources. Add Atlas for multi-specialist integration or conflict.

Route important technical construction to an independent reviewer. A simple prose task does not automatically need the whole Council. Record artifact ownership, dependencies, inputs, acceptance evidence, and scope. If no specialist matches, Atlas clarifies the objective.
