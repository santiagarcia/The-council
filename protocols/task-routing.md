# Task routing

Start with the smallest team that covers the objective. Transparent lexical routing recommends roles and reasons; it never spawns agents. Inspect the actual objective and assign one owner per artifact.

| Task | Selective team |
| --- | --- |
| Mathematical derivation | Noether, relevant domain specialist, Gauss, Vera |
| Numerical method | Gauss, Ada, Vera; Noether when formal assumptions matter |
| Interface or CLI | Maya, Ada, Nico, Vera |
| Presentation | Iris, relevant specialist, Maya, Nico |
| Tutorial or installation guide | Ada, Iris, Maya, Nico |
| New scientific concept | Curie or relevant expert, Noether, Iris, Nico |
| Final deliverable review | Vera for correctness; Nico for cold-read comprehension |
| Primary source research | Scout; relevant experts when needed |

Atlas coordinates scope, integration, and conflict when needed. Curie evaluates physical meaning; Gauss numerical behavior; Noether mathematical foundations. Ada implements; Maya evaluates the interaction; Iris communicates; Nico exposes missing context; Vera independently verifies; Scout researches sources.

The CLI matches explicit terms and task families; it cannot infer an unstated scientific domain. Add a specialist explicitly when needed. Avoid the full Council by default; `dispatch --all` is deliberate opt-in. A route is not an authenticated assignment or proof of review independence.

Nico's dispatch assignment has a separate isolated handoff. The parent must prepare `council review --agent nico --mode cold-read --artifact PATH` and send that packet alone; do not send common project context, the objective, or other specialists' answers. Sequence final comprehension after the public artifact exists, without leaking technical learning from earlier drafts.

For important construction, sequence independent correctness review after the actual artifact and evidence exist. For final deliverables, record both correctness and comprehension; incomprehensibility or false simplification blocks acceptance.
